# 拾题手机端 Android

原生 Android WebView 客户端（1.5.2）。手机版网页已作为 APK 资源内置，电脑关机、网络断开或从未配置同步时都可以直接打开使用。

- 题目、答案、分类和图片/PDF 附件优先写入手机 IndexedDB，重启应用后仍保留。
- 题目内容和答案/解析各有独立的拍照、相册选择、预览、重新裁剪和移除入口；拍照确认后立即进入裁剪界面。
- 图片可拖动、缩放并切换原比例/题目横图/方形裁剪，确认后压缩保存；PDF 仅作为题目附件直接处理。
- Android 拍照通过系统后置相机和临时授权 URI 完成，不申请相机或存储权限。
- 上传成功只更新“已同步”状态，不删除手机题库；离线编辑和删除会在下次连接时继续同步。
- 科目固定为英语、数学、822控制；支持多级知识分类、独立题型、分类增删和本机智能组卷。
- 智能组卷仅开放数学与 822控制，按“知识大类 × 题型”分别配置数量。
- 电脑地址和配对令牌是可选项；连接后双向合并电脑题库，电脑空数据不会覆盖手机。
- 可导入、导出包含附件的手机完整备份；“找回旧版待上传箱”可迁移 1.4.0 的未上传草稿。
- APK 使用 AndroidX `WebViewAssetLoader` 从 `https://appassets.androidplatform.net` 加载内置页面，禁用文件访问和 `file://` 跨域万能权限。
- Manifest 只保留联网权限；旧版本保存的电脑地址与令牌会一次性迁移到手机版本地设置。
