# 拾题 · 考研错题本

双击 `打开错题本.command` 启动本地网页服务，再打开 `index.html`。它也可以作为 PWA 安装到浏览器里。错题文字、计划和完成记录保存在当前浏览器的本地存储中，图片/PDF 附件保存在浏览器 IndexedDB 中。Windows Electron 版还内置了一个局域网同步接收器，并会显示可复制的本机 / 局域网地址，安卓端可以直接把数据推回 Windows。

错题支持按科目、模块、单元、知识点和标签整理；点击卡片先看题目，再展开答案、反思和奥技结论，觉得归类不对时还能直接点“修改归类”重选科目、模块、单元和标签。复习时可标记“不会 / 模糊 / 掌握”，分别安排 1 / 3 / 7 天后再复习，并记录复习次数、复习日期和当天已完成题目。今日复习页可以设置每日总量，并按“科目 · 模块”自动分配题目，缺口会自动用更该刷的旧题补齐，排题时会优先选复习次数更少的题目；内置数学、英语、政治、专业课轮转模板，方便按阶段切换每天看几题。今日复习页还可以导出 JSON 备份。

页面分成五块：

- `错题库`：录入和检索错题
- `今日复习`：自动排题和复习反馈
- `学习洞察`：数据概览与同步状态
- `科目配置`：四科模块选项、滚动模板、标签建议
- `使用指引`：功能总览、使用路径、逻辑架构、未来想法

复习日历会按当前系统月份显示，并以实际完成记录标记已复习日期。

在「科目配置」页里可以先把数学、英语、政治、专业课的模块选项搭起来；在「使用指引」页里还能直接配置同步地址、保存用户标识、导入/导出备份。更完整的上手步骤见 `使用说明书.md`。

导出的备份 JSON 会带上题库、模块配置、计划、完成记录、同步配置和附件正文。

后续迭代交接记录见 `AGENT_HANDOFF.md`。

每张错题卡还会显示入库日期、累计复习次数、最近复习日期、复习日期档案，以及当前分类层级和标签总数。
这些详细信息默认收起，点击“查看学习档案”时才展示；日常浏览只保留科目、模块、标题和复习次数。若后面要改题目的归类，直接点卡片里的“修改归类”即可。

## 同步接口约定

前端会把当前状态 `POST` 到你配置的同步地址，JSON 里包含：

- `deviceId`
- `sync`
- `questions`
- `plan`
- `done`
- `dayPlan`
- `subjectConfig`
- `assets`

服务端返回同样结构的 JSON 即可完成双向同步；如果只返回部分字段，前端会只合并能识别的部分。

Windows Electron 版默认会起一个本地同步接收器，地址通常是：

```text
http://127.0.0.1:17332
```

安卓设备在同一局域网下可直接连 Windows 的局域网 IP，例如：

```text
http://192.168.1.8:17332
```

同步请求还必须带 Windows 桌面版显示的配对令牌；令牌保存在 Electron userData 下的 `sync-token.txt`，不要公开给其他人。

在桌面版「使用指引」页里也能直接看到这些地址并一键复制。

备份导入会覆盖本地题库、计划和完成记录，并重建附件正文。

## 打包 Windows EXE

在 Windows 或装有 Windows 构建环境的机器中打开此文件夹，执行：

```bash
npm install
npm run dist
```

生成的便携版 EXE 会在 `dist/` 文件夹内。应用不联网，数据保存在本机 Electron userData 目录。
